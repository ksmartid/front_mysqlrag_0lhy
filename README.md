# 쇼핑몰 AI 서비스 프론트엔드

Node.js 20 이상 권장. 백엔드와 DB 설정(05~07 SQL 포함) 후 `.env.example`을 `.env`로 복사한다.

```powershell
npm install
npm run dev
```

`http://127.0.0.1:5173` 접속 후 상단 **사용자**에서 관리자·판매자·구매자를 전환한다. 선택한 사용자 ID는 `X-User-Id` 헤더로 전송되고, 권한 범위는 백엔드가 DB 기준으로 판단한다.

| 역할 | 메뉴 |
|---|---|
| 관리자 | 운영 대시보드, 불만 처리 센터(유사 사례 RAG·답변 승인·처리 결과), 후기 분석, 통합 RAG 상담, 운영 인사이트, RAG 색인 관리, 문서·매뉴얼 적재, AI 이력 |
| 판매자 | 판매 대시보드, 본인 상품 불만 처리, 후기 관리(AI 요약·답글 초안), RAG 상담, 운영 인사이트, AI 이력 |
| 구매자 | 내 쇼핑, AI 쇼핑 상담(정책·후기·내 문의 근거), 상품 후기 요약·작성, 문의·불만 접수·답변 확인, 맞춤 추천 |

처음 실행할 때는 관리자로 **RAG 색인 관리 → 증분 동기화**를 한 번 실행해 후기·불만을 벡터 색인한다. 이후에는 후기 작성·불만 접수·처리 결과 저장 시 자동 색인된다.

소스 구조: `src/api.js`(요청·헤더), `src/ui.jsx`(공통 컴포넌트·음성), `src/pages/*`(역할별 화면), `src/main.jsx`(사용자 전환·메뉴). 브라우저 음성 인식과 음성 읽기는 Web Speech API 지원 환경에서 동작한다. `.env`와 `node_modules`는 압축파일에 포함하지 않는다.
